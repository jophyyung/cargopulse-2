# CargoPulse 0.1.0 release candidate

Synthetic Recover decision support now runs as a persistent authenticated web
application. Imports retain immutable source artifacts and provenance; scenarios
queue leased durable jobs. HiGHS and two reference policies produce real plans,
independently checked against physical resources, safety evidence and metric
denominators. Operators inspect candidates, urgency, assignments and explanations,
then record an exact-hash human decision with an immutable receipt and audit trail.

The workspace includes English/Traditional Chinese navigation, role restrictions,
policy drafts with separate-manager publication, source/plan lineage and JSON/CSV/
PDF exports. OIDC/MFA, production cookies/CSP, private object adapters, PostgreSQL
row security, telemetry, migration/container builds and recovery tooling are present.

Independent QA identified rule-publication bypass, artifact-loss handling, exhausted
lease state, token authorized-party validation, forged metric evidence and future
candidate evidence. Reproductions were retained and corrected. Browser sessions
also rotate and revoke the presented cookie on successful reauthentication.

The security follow-up now retains verified OIDC assurance across role changes,
transactionally revokes sessions on account disable and prevents re-enable revival.
Schema0005, prefixed production cookies, stable read-only CSRF, private-DOM lifecycle
and expiry metadata, no-referrer/CSP, CSV filename checks and strict owned S3 XML
protocol parsing have new executable coverage. Minimal API/web runtime closures
and patched Alpine PostgreSQL pass the exact-image HIGH/CRITICAL gate, with lower
findings retained. Existing data was logically migrated with history/object hash
checks and write-preserving failure handling; the original volume remains intact.

**This candidate is not approved for public L1 release.** Lower image findings,
remaining security/owner acceptance, real deployment/identity/storage/monitoring
checks and owner/legal sign-offs remain open. Local independent installation
evidence is versioned separately; it is not hosted CI or public acceptance.
Protect, airline connectors and operational
writes are unavailable. No airline endorsement, physical clearance, live performance
claim, external booking or production availability is implied.
